## Included

- 56 clean-room public beta Skills in one repository;
- public examples, playbooks, method cards, and discovery docs;

- compatibility and runtime smoke harnesses;
- public documentation, tests, CI, catalog, provenance records, sanitization records, and brand assets.

## Excluded

- customer and personal data;
- credentials, tokens, keys, and environment files;
- private machine paths and infrastructure;
- private templates and internal operating rules;
- third-party vendor directories and binary media;
- unverified compatibility and outcome claims.

The repository contains detector rule names and public configuration directory names. Those strings are auditable code and documentation, not credential values or private locations.

Automated scanning complements human review; it does not prove ownership, factual accuracy, or safety for every use.
