# Example runs

These examples show how a user can try the public Skills without private data or a live customer project.

- [Wenzhen fuzzy request](wenzhen-fuzzy-request.md): turn a vague product ask into a falsifiable task contract.
- [Deck from outline](deck-from-outline.md): turn an outline into a verifiable presentation request.
- [Adversarial review verdict](adversarial-review-verdict.md): review a small change through explicit release lenses.
- [Orient an unknown repository](orient-unknown-repository.md): map a codebase before editing.
- [Support triage agent design](agent-designer-support-triage.md): design an agent with bounded tools and human authority.
- [Public redline hook](hook-factory-public-redline.md): turn a repeated public-docs failure into a deterministic guardrail.
- [API pagination contract review](api-review-pagination-contract.md): review an endpoint before clients depend on an unbounded contract.
- [Checkout accessibility audit](a11y-checkout-flow.md): turn accessibility into user ability checks before release.
- [Database list endpoint review](database-performance-list-endpoint.md): catch N+1 and unbounded list risk.
- [AI visibility for open-source docs](ai-seo-open-source-docs.md): make docs easier for AI assistants to cite accurately.
- [Launch post with publication boundary](content-production-launch-boundary.md): create community copy without bypassing approval.

The examples are illustrative and sanitized. They are not customer transcripts.
