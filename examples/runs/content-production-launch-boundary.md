# Example run: Launch post with publication boundary

## User input

```text
Turn this repository release into a post for a developer community. Keep it factual and ask for useful feedback.
```

## Skill to try

`dayan-content-production`

## Expected direction

The Skill should produce a content package, not silently publish it.

## Minimal output shape

```text
Audience:
Developers and AI workflow builders who rebuild prompts, guardrails, review steps, and evidence checks.

Core claim:
The repository contains 56 installable public beta Skills, public playbooks, example runs, and validators for controllable AI workflows.

CTA:
Try one Skill in a clean temporary home and report install or trigger behavior.

Publication boundary:
Final channel, account, copy, timing, and reply owner require explicit approval. Do not buy stars, mass-post, or evade account restrictions.
```

## What to verify

- Facts are separated from opinion.
- The CTA asks for useful feedback, not artificial engagement.
- External publishing authority is explicit.
