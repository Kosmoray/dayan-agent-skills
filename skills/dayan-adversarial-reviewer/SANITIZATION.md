# Sanitization record

The public beta package is intentionally generic.

## Included

- brand-neutral workflow instructions;
- a public rubric reference;
- one passing JSON report fixture;
- one blocking JSON report fixture;
- a deterministic verifier and tests.

## Excluded

- real organization names or private stakeholder data;
- credentials, tokens, keys, or environment files;
- private machine paths;
- private operational details;
- unlicensed third-party assets;
- claims that the verifier cannot prove.

Automated validation checks schema and redline patterns. Human review is still required for domain judgment and consequential release approval.
