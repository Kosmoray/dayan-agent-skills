# Dayan HTML

Use this Skill for a scrolling report, proposal, dashboard, explainer, or landing page. Use a presentation Skill for slide-by-slide projection.

## Build contract

1. Define the reader, one primary decision or action, factual sources, and delivery scope.
2. Structure the page as hero, executive answer, evidence sections, decision or action block, and source notes.
3. Use semantic HTML, visible focus states, keyboard-safe interactions, responsive layout, and reduced-motion support.
4. Embed required assets or use repository-relative files; never depend on private machine paths.
5. Keep claims proportional to evidence. Label assumptions and unverified outcomes.
6. Verify headings, landmarks, contrast, overflow, broken links, remote dependencies, and audience-visible production notes.

Self-contained means portable at delivery time; it does not prove visual quality, factual accuracy, or user acceptance. Those require separate review.
