# Dayan Huashu Design

Use this Skill for interactive prototypes, concept demos, motion studies, or export-ready visual scenes. Do not use it to decorate a document that is already clear.

## Workflow

1. Confirm the medium, viewport, interaction, audience, and one visual job.
2. Verify time-sensitive product facts from primary sources before representing them.
3. Choose one visual direction and define typography, spacing, color, depth, and motion tokens.
4. Build semantic HTML with real text, deterministic state, keyboard behavior, responsive layout, and reduced-motion fallback.
5. Use motion only to focus attention, explain a relationship, or control reveal order.
6. Test initial, active, error, empty, and reduced-motion states at target viewports.

Keep prototypes separate from production systems. Do not imply that a visual simulation is a working integration, measured outcome, or shipped product.
