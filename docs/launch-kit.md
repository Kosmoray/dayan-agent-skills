## GitHub release / pinned post

### Title

56 Skills. One control library for AI agents.

### Body

Most agent projects keep rebuilding the same missing layer: how to frame the work, constrain authority, preserve evidence, stop unsafe actions, and verify whether an output earned its completion claim.

Dayan Agent Skills packages those control layers in one repository:

- Create: presentations, HTML, diagrams, visual systems, content, and responsive interfaces.
- Think: problem framing, planning, research, architecture decisions, and independent second opinions.
- Build: agents, hooks, prompts, roles, dispatch, local tools, and reusable Skills.
- Verify & Grow: adversarial review, accessibility, API contracts, database performance, system triage, and AI visibility.

Start with one of three one-screen demos:

1. Wenzhen: a vague request becomes a falsifiable task contract.
2. Dayan Deck: a crowded slide becomes one visible decision.
3. Adversarial Reviewer: “looks good” becomes an evidence-backed release verdict.

All 56 Skills live in one repository with one issue tracker, release history, contributor graph, and star count. Each package publishes its boundary, starter contract, provenance, sanitization record, and known evidence gap.

Public beta means inspectable and installable. It does not mean every Skill has proven behavior in every runtime.

Try a Skill. If this is a library you want to return to, star it:
<https://github.com/Kosmoray/dayan-agent-skills>

### Body

I kept running into the same problem: the model was capable, but every project had to recreate the control layer around it.

So I consolidated 56 reusable Skills into one MIT-licensed repository. They cover task framing, planning, repository orientation, agent and hook design, code/API/a11y review, HTML/deck/diagram production, evidence handling, and more.

This is intentionally one repository rather than dozens of tiny repos. The useful unit is the library: shared installer, catalog, fixtures, validators, provenance, and known blockers.
