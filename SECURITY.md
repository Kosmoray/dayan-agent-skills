# Security

This repository is an early public beta.

Do not include credentials, private paths, customer data, internal infrastructure details, or executable downloads from untrusted sources. Report a suspected leak through the repository's private [security advisory form](https://github.com/Kosmoray/dayan-agent-skills/security/advisories/new); do not open a public issue containing sensitive material.

The beta installer refuses to overwrite existing Skill directories. Review every Skill before installation: Skills can contain instructions and executable helpers.
